# public/ assets

Static files served from the site root.

- `favicon.svg` — site favicon (YA monogram).
- `avatar.svg` — optional avatar placeholder. Replace with a real photo
  (`avatar.png` / `avatar.jpg`) if you want one in the hero/about.
- `robots.txt`, `sitemap.xml` — SEO. Update the URLs if your domain changes.
- `.nojekyll` — tells GitHub Pages not to run Jekyll (needed for `_next/` assets).
- `resume.pdf` — **add your own resume here.** The navbar "Resume" button links
  to `/resume.pdf`. Drop your PDF in this folder with that exact name.
